# WordPress ReadMe **WordPress — Semantic Personal Publishing Platform** ## First Things First Welcome to WordPress! WordPress is an open-source publishing platform built and improved by developers and contributors around the world. Thank you for using WordPress. — Matt Mullenweg ## Installation: Famous 5-Minute Install 1. Extract the WordPress package into an empty directory and upload the files to your web server. 2. Open `wp-admin/install.php` in your browser. 3. Follow the instructions to configure your database connection and create the `wp-config.php` file. If automatic configuration does not work: - Open `wp-config-sample.php` in a text editor. - Enter your database connection details. - Save the file as `wp-config.php`. - Open `wp-admin/install.php` again. 4. The installer will create the required database tables. If an error occurs, check your database configuration. 5. Choose your administrator username and password. If a password is generated automatically, save it securely. 6. Log in through `wp-login.php` using your credentials. For help, visit the [WordPress Support Forums](https://wordpress.org/support/forums/). ## Updating ### Using the Automatic Updater 1. Open `wp-admin/update-core.php` in your browser. 2. Follow the instructions to complete the update. ### Updating Manually 1. Back up your website files and database. 2. Keep copies of any files you have modified. 3. Replace the old WordPress files with the new files. 4. Open `wp-admin/upgrade.php` in your browser if a database upgrade is required. 5. Verify that your website works correctly. ## Migrating from Other Systems WordPress supports importing content from several other publishing systems. First, install and configure WordPress. Then use the available import tools in `wp-admin/import.php`. See the [WordPress Importing Content Guide](https://wordpress.org/documentation/article/importing-content/). ## System Requirements ### Minimum Requirements (Historical) The original document listed these minimum versions: - **PHP:** 5.6.20 or greater - **MySQL:** 5.0 or greater These are historical requirements and should not be used for a new installation. ### Recommendations The original document recommended: - **PHP:** 7.4 or greater - **MySQL:** 5.7 or greater, or **MariaDB:** 10.2 or greater - Apache `mod_rewrite` support - HTTPS support - A link to [WordPress.org](https://wordpress.org/) For current requirements, consult the official [WordPress Requirements page](https://wordpress.org/about/requirements/). ## Online Resources - [WordPress Documentation](https://wordpress.org/documentation/) — Guides for installing, configuring, and using WordPress. - [WordPress News](https://wordpress.org/news/) — Official news and updates. - [WordPress Support Forums](https://wordpress.org/support/forums/) — Community support and troubleshooting. - [WordPress Developer Resources](https://developer.wordpress.org/) — Technical documentation for developers. - [WordPress Plugin Developer Handbook](https://developer.wordpress.org/plugins/) — Learn how to create plugins. ## Final Notes - Report bugs and share suggestions through the [WordPress Support Forums](https://wordpress.org/support/forums/). - WordPress provides a plugin API that allows developers to extend its functionality. - Avoid modifying WordPress core files directly. Use plugins or themes to customize your website. ## Share the Love If you enjoy WordPress, share it with others, contribute to the community, or support its development.
